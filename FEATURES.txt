AI MEDIA STUDIO — FEATURES
Real-estate focused AI image, video, and audio workstation
Built with Grok 4.5

Setup, keys, Resolve path, and sharing: see README.md (source of truth for install).
This file lists product capabilities.

==============================================================================
OVERVIEW
==============================================================================
Pay-per-use desktop app for listing videographers. Stage empties, lock camera
moves, invent stills then bridge them, repair stills/video, denoise clips,
interpolate / slow-mo, generate audio, and run creative shots — then send
results to DaVinci Resolve.

Providers:
  fal.ai   — main generation (Studio, Tools, Vision, Audio; FE 1080p proxy).
             Admin key needed only to display fal balance.
  xAI      — Grok Enhance / QC (optional). Grok Imagine on fal uses FAL key.
  Runware  — Frame Editor / Aleph only (optional).

First run: Quick Start wizard. Reopen via Help (?) anytime.

==============================================================================
CREATIVE VISION
==============================================================================
Cinematic playground (separate from listing camera-lock staging).
Modes (left → right):

  Text → Image (T2I)
    Invent a still first, then Send to Start / End frame for a Bridge,
    or Send to Studio Image. No motion language injected.
    Models (fal): Flux 2 Pro / Flux 2 / Flex / 1.1 Pro Ultra,
                  Nano Banana / Nano Banana 2 / Pro,
                  Seedream 4.5 / 5.0 Lite / 5.0 Pro, Recraft V3
    Still photography helpers only:
      Framing / composition · Lens look · Lighting · Still style presets
    Aspect / size presets (model-specific; some support 0.5K–4K)

  Text → Video (T2V)
    e.g. Veo 3.1 / Veo 3.1 Fast / Reference pack, Luma Ray 2
    Veo on fal: ~$0.40/s standard, ~$0.15/s Fast (totals = rate × duration)

  Image → Video (I2V)
    Start still → motion (Veo, Kling O3 Pro, Seedance 2.0, Hailuo, …)

  Bridge / Connect
    Start frame + end frame → in-between (Veo first→last, Hailuo start+end)

Shared Vision UI:
  - Camera / shot helpers on video modes (shot type, lens feel, motion, style)
  - Every helper dropdown includes (None) to skip that dimension
  - Rebuild prompt: Replace / Append from active helpers only
  - Creative direction field — Enhance only (intent for Grok; never sent
    as-is on Generate; empty = helpers + prompt only)
  - Subject Library + Vision presets (collapsible expanders)
  - Grok Enhance (model-aware; T2I never adds push-in / pan language)
  - Negative prompt (optional)
  - Cost labels are job totals, e.g.
      Est. cost: $3.20 · 8s (Veo 3.1)
      Est. cost: $0.03 · 1 image (Flux 2 Pro (T2I))
    never a bare unit rate alone
  - Optional cost guard (Settings: warn at $2+ / $5+; default off)
  - Result: play (video) / preview (still), Library, Resolve, Send to ▾

==============================================================================
FRAME EDITOR (Aleph 2.0)
==============================================================================
Requires Runware API key — not fal (fal only for optional 1080p proxy).

Keyframe-guided video edit:
  - Upload source video
  - Auto-downscale to 1080p-class proxy when needed (fal scale-video)
  - Filmstrip of sampled frames (JPEG thumbs; LRU-bounded cache)
  - Up to 5 keyframes (first / last / timestamp)
  - Send frame to Studio for cleanup gens → pin still back
  - Prompt + Grok Enhance
  - Generate via Aleph 2.0
  - Result → Library, Show in folder, Send to Resolve

SETTINGS / DISK SAFETY
==============================================================================
- fal / xAI / Runware keys (local app data only)
- Output folder (persisted across sessions)
- Library / outputs retention: Never / 7 / 14 / 30 / 90 days
- Apply retention now
- Clear caches (app-owned dirs only under output root + handoff —
  never deletes arbitrary user folders outside the app tree)
- Cost guard for expensive generates (default off; warn at $2+ or $5+)
- Hide missing Library rows

==============================================================================
COST LABELS
==============================================================================
UI cost lines are estimated job totals, not bare rates:
  Est. cost: $X.XX · {unit} ({model})
  e.g. $3.20 · 8s for Veo 3.1 standard ($0.40/s × 8s on fal)
  e.g. $0.90 · 6s for Veo 3.1 Fast ($0.15/s × 6s)
  e.g. $0.03 · 1 image for Flux T2I
Estimates are conservative UI ballparks, not billing. No invented audio
surcharge unless the provider quotes one.

==============================================================================
PER-TAB BUSY
==============================================================================
Long-running jobs lock only their scope (image, video, tools, vision,
audio, frame_editor, enhance, …). Other tabs stay usable.

==============================================================================
GROK ENHANCE
==============================================================================
Available across Studio, Tools, Creative Vision, Frame Editor, Audio:
  - Rewrites prompts for the selected model
  - Uses vision when a still/reference is present
  - Scenario-aware constraints
  - Does not auto-switch models
  - Creative Vision: optional creative_direction is Enhance-only intent
  - T2I Enhance never injects camera motion language
  - Skipped where tools are pure control (e.g. Topaz denoise)
