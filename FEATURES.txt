==============================================================================
OVERVIEW
==============================================================================
Pay-per-use desktop app for listing videographers. Stage empties, lock camera
moves, invent stills then bridge them, repair stills/video, denoise clips,
interpolate / slow-mo, generate audio, and run creative shots — then send
results to DaVinci Resolve.

Providers:
  fal.ai   — main generation (Studio, Tools, Vision, Audio; FE 1080p proxy).
             Admin key needed only to display fal balance.
  xAI      — Grok Enhance / QC (optional). Grok Imagine on fal uses FAL key.
  Runware  — Frame Editor / Aleph only (optional).

First run: Quick Start wizard. Reopen via Help (?) anytime.

==============================================================================
CHARACTERS (reusable stills)
==============================================================================
Peer tab to save realtor / talent / hero stills for one-click reuse — local only
(data/characters.json + data/character_stills/). Not a Library replacement;
Voice Clone stays under Audio.

- Upload still, or pick from Previously used / From Resolve; optional Open Library
- Name (required) + optional notes / tags → Save
- Multi-angle: up to 3 stills per character (primary + optional extras); list shows
  primary thumb; Edit manages angles
- Generate variation: simple I2I face-lock (Flux 2 Pro) from primary still — save as
  new character, add as angle, or replace primary
- Shortcuts: “Save as character” / “Save current still as character” from Motion Sync,
  Director (active shot ref), and Studio Image (source or result) prefills Characters
- Saved list: thumbnail, name, notes; Edit · Delete · Show in folder ·
  Use in Motion Sync (sets primary still + switches to Motion Sync)
- Empty state explains one-click use in Motion Sync, Director, and more
- Survives app restart (local store)

==============================================================================
MOTION SYNC (character + driving video)
==============================================================================
Peer tab for motion transfer: a character still performs actions from a driving
clip (realtor hooks, trend content) while preserving identity.

- Character still: upload / Previously used / From Resolve (full-body or clear
  upper body, good light, simple background preferred)
- Motion reference: upload video / From Resolve; duration shown when loaded
  (clean single subject, 3–10s ideal; long/large clips auto-proxy — original kept)
- Best-practice tips always visible on the tab
- Models (true motion-control only):
    Kling Motion Control V3 Pro · V3 Standard · Kling 2.6 Motion Control · Wan Motion
- Kling: keep original audio (default on); character orientation match video / image
- Wan: adapt motion · enhance identity · acceleration
- Optional prompt + light helper chips + Enhance
- Est. cost under Generate (Studio chrome; duration × $/s)
- Generate → Library / Show in folder / Send to Resolve
- Clear blocks if still or motion clip is missing; friendly errors for no-person /
  too short / too large / unsupported format

==============================================================================
VFX (in-scene + element plates)
==============================================================================
Peer tab for visual effects — not for general plate staging (use Studio / Vision).

Sub-tabs:
  In-scene — effect integrated into a full still or clip (geometry + lighting lock)
  Element plates — isolated effect on pure black / clean bg for Resolve Screen or Add

Effect preset packs (physics-aware prompt inject; prompt stays fully editable):
  Fire / heat haze · Smoke / dust · Energy / power surge · Rain / snow / fog ·
  Debris / impact · Lens flare / light leak · **Custom** (user-written only; no
  pack inject; Enhance rewrites for model + In-scene/Element without forcing a category)

Shared controls:
  Source still or clip · Strength / intensity · Duration · Resolution ·
  Model picker (Grok Imagine 1.5, Kling, Seedance, H3, Veo Fast, video-edit models) ·
  Enhance (mode-aware) · Est. cost under Generate (Studio chrome) ·
  Library / Show in folder / Send to Resolve

Element plates: obvious “Pure black / clean plate (Screen · Add in Resolve)” checkbox
and tip copy. In-scene keeps plate geometry/lighting language in the prompt.

DIRECTOR (multi-shot)
==============================================================================
Peer tab to Studio / Creative Vision / Frame Editor — generate multi-shot clips
from a master brief + ordered shot list (not for editing existing plates).

- Master: global prompt, total duration (model max, e.g. 3–15s), aspect, style pack
  (None | Cinematic | Marvel-style | Documentary | Luxury RE), multi-shot model only
- Models (multi-shot / reference): Kling V3 Pro / Standard Multi-Shot, Kling O3 Pro /
  Standard Multi-Shot; **Grok Imagine 1.5 · Reference storyboard** (single clip from
  ordered shot refs via T2V/I2V/R2V — not Kling multi_prompt). Seedance / Wan / H3
  stay single-clip outside Director.
- Est. cost: Studio-style bordered block directly under Generate; live on model /
  duration / audio
- Shot list 2–6 rows (hard-capped by model): start/end time, camera preset
  (Push in / Orbit / Crane / Static / Pan / Tilt / Handheld…), per-shot action,
  optional ref still (upload / Previously used / From Resolve) with ~64px thumbnail
  + filename (Clear ref; empty state “No ref still”)
- Phase 2 polish (prompt-level): audio intent (Generate audio + No music | Soft bed |
  Full score + optional SFX notes); continuity toggles (Same character / location /
  time of day); per-gap transition (Hard cut | Soft dissolve | Continuous — no cut,
  refs as motion keyframes) with global default applied to all gaps + control between
  Shot N and N+1; Continuous fail-safe needs ordered times + ref stills on both sides;
  optional energy curve (restrained → peak → resolve); vision notes (Enhance-only);
  output Single multi-shot clip (default) or Clip pack + shot-list .txt sidecar
- Fail-safes: times inside [0, duration], no overlaps, min 1s per shot, required
  action prompts; Generate blocked with clear messages
- Enhance: master + style + polish + every shot → shot-aware rewrite (vision notes
  weave into tone; not dumped raw unless useful)
- Generate → one multi-shot video (fal multi_prompt); optional shot-list sidecar for
  Resolve; Library + Show in folder + Send to Resolve
- Library Send to ▾ → Director ▶ → Shot 1…N assigns that shot’s ref still + thumbnail
  (creates Shot 1 if empty; focuses Director + highlights the row)
- Cost est. = duration × model $/s

    Side-by-side (labeled) or vertical stack (phone posts)

  - Draw/place colored boxes on the still (small left + large Comparison stage)
  - L/T/W/H are % of the source image content box (CONTAIN letterbox); both
    previews share that coordinate system (no panel-size offset between them)
  - Large stage: full-brightness source while placing boxes; region boxes live

  - Per-box prompts; composite hard-fails if annotation still cannot be built
    (never ships a raw still + box text as the model input)
  - Model list filtered to Seedream / annotation-capable models

RESOLVE INTEGRATION
==============================================================================

- Send to Resolve (Tier A smarter send) from Studio, Tools, Frame Editor, Audio, Library
    (DaVinci Resolve logo asset on Send buttons):
    - Media Pool bin: AI Media Studio / <Job name or today’s date>
    - Optional place on video track (default V2) at playhead when scripting allows
    - Optional timeline/clip marker note (model · scenario · cost when known)

    Studio Image / Video, Tools image + video forms, Creative Vision

- Prefer graded proxies; Render in Place when needed (manual in Resolve)
- Handoff auto-purge (~7 days / ~200 files) + Clear handoff cache
- Single-instance: Resolve Send reuses the open Studio window (no second UI)

COST LABELS

  Est. cost: $X.XX · {unit} ({model})
  e.g. $3.20 · 8s for Veo 3.1 standard ($0.40/s × 8s on fal)

Estimates are conservative UI ballparks, not billing. No invented audio
surcharge unless the provider quotes one.

==============================================================================
GROK ENHANCE
==============================================================================
Available across Studio, Tools, Creative Vision, Frame Editor, Audio:
  - Rewrites prompts for the selected model
  - Uses vision when a still/reference is present
  - Scenario-aware constraints
  - Does not auto-switch models
  - Creative Vision: optional “Creative direction for Enhance” field is
    Enhance-only intent (empty = helpers + main prompt only; never raw on Generate)
  - Helper (None) values are omitted from Enhance guidance
  - T2I / I2I Enhance never injects camera motion language
  - Skipped where tools are pure control (e.g. Topaz denoise)
  - Star the enhanced text after Enhance to keep it in Favorites
