==============================================================================
OVERVIEW
==============================================================================
Pay-per-use desktop app for listing videographers. Stage empties, lock camera
moves, invent stills then bridge them, repair stills/video, denoise clips,
interpolate / slow-mo, generate audio, and run creative shots — then send
results to DaVinci Resolve.

Providers:
  fal.ai   — main generation (Studio, Tools, Vision, Audio; FE 1080p proxy).
             Admin key needed only to display fal balance.
  xAI      — Grok Enhance / QC (optional). Grok Imagine on fal uses FAL key.
  Runware  — Frame Editor / Aleph only (optional).

First run: Quick Start wizard. Reopen via Help (?) anytime.

JOB / LISTING (app-level)
==============================================================================
Optional “Job / Listing” field on the scenario bar (shared by Studio, Creative
Vision, Tools, Frame Editor, Audio):
  - e.g. address, client, shoot date
  - Last-used value is persisted across sessions
  - When set, final media is saved under:
        <output_root>/jobs/<safe-job-name>/<YYYY-MM-DD>/
  - Empty = current flat dated layout:
        <output_root>/<YYYY-MM-DD>/
  - History / Library metadata store the job label; no cloud sync
  - Caches (_region, previews, Aleph proxies) stay under the output root
  - Library can also assign (or clear) a job after the fact — see LIBRARY

==============================================================================
CREATIVE VISION
==============================================================================
Cinematic playground (separate from listing camera-lock staging).
Modes (left → right):

  Text → Image (T2I)
    Invent a still with no source required. Still-only helpers — no camera
    motion language (no push-in / pan / orbit on rebuild or Enhance).
    Models (fal, as registered): Flux 2 Pro / Flux 2 / Flex / 1.1 Pro Ultra,
      Nano Banana / Nano Banana 2 / Pro, Seedream 4.5 / 5.0 Lite / 5.0 Pro,
      Recraft V3
    Still photography helpers:
      Framing / composition · Lens look · Lighting · Still style presets
      Each helper includes (None) = omit from Rebuild + Enhance
    Multi-variant: # Images 1–4 (UI batch; sequential when API is 1-at-a-time)
      Cost estimate = per-image × selected count (full job total, not capped at
      API max). Label notes “N sequential runs” when batching singles.
      Multi-output in one fal call when the model allows; else sequential
      singles (vision tab busy only — not a global queue)
      Each still lands as a separate Library item with its own Send to ▾
      Variant strip in Result to select which still to send
    Result Send to ▾ includes → Start frame / → End frame (this tab) for
    bridge handoff, plus Studio / Frame Editor / Tools / Resolve as elsewhere

  Image → Image (I2I) — creative still edit (Aleph plate round-trip)
    Source still required (upload, Previously used, From Resolve, or Send from
    Frame Editor / Library / Studio). Single source for v1 (not multi-ref).
    Models (fal edit): Flux 2 Pro / Max / Flex, Flux Kontext Pro,
                       Nano Banana / 2 / Pro edit, Seedream 5 Pro edit
    Strength slider when the API exposes it (Flux family)
    Same still-only helpers + (None); Creative direction for Enhance;
    Grok Enhance with vision on the source still
    Result → Frame Editor · keyframe, Start / End / I2V, Library

  Text → Video (T2V)
    e.g. Veo 3.1 / Veo 3.1 Fast / Reference pack, Luma Ray 2
    Veo on fal: ~$0.40/s standard, ~$0.15/s Fast (totals = rate × duration)

  Image → Video (I2V)
    Start still → motion (Veo, Kling O3 Pro, Seedance 2.0, Hailuo, …)

  Bridge / Connect
    Start frame + end frame → in-between (Veo first→last, Hailuo start+end)

Shared Vision UI:
  - Video modes: Camera / shot helpers (shot type, lens feel, motion, style)
  - Still modes (T2I / I2I): still photography helpers only (no motion)
  - Every helper dropdown includes (None) — omit that dimension from Rebuild
    prompt and from Enhance guidance (active helpers only)
  - Rebuild prompt: Replace / Append from active helpers only
  - Creative direction for Enhance (optional field):
      Enhance-only intent for Grok — never sent raw on Generate
      Empty = current behavior (helpers + prompt only)
  - Subject Library + Vision presets (collapsible expanders)
  - Grok Enhance (model-aware; still modes never add push-in / pan language)
  - Negative prompt (optional)
  - Cost labels are job totals, e.g.
      Est. cost: $3.20 · 8s (Veo 3.1)
      Est. cost: $0.03 · 1 image (Flux 2 Pro (T2I))
      Est. cost: $0.12 · 4 images (Flux 2 Pro (T2I))
    never a bare unit rate alone
  - Optional cost guard (Settings: warn at $2+ / $5+; default off)
  - Result: play (video, CONTAIN) / preview (still), Library, Resolve, Send to ▾
  - Previously used + From Resolve stills on I2I / I2V / bridge start where relevant

Helper (None) also applies to Studio scene-builder helpers (style / density /
camera) and Audio prompt builders (Music / SFX / Ambience / Video→SFX chips)
where a dimension injects text into Rebuild — Off/None skips that text.

FRAME EDITOR (Aleph 2.0)
==============================================================================
Requires Runware API key — not fal (fal only for optional 1080p proxy).

Keyframe-guided video edit (Aleph frameImages: first | last | timestamp + prompt):
  - Upload source video; Previously used + From Resolve (stills → pin, clips → source)
  - Auto-downscale to 1080p-class proxy when needed (fal scale-video); 2–30s source
  - Edit intent helper (UI only — no invented API params):
      Apply through clip | Transition first→last | Custom timestamps
      One keyframe ≈ apply look through clip; first+last ≈ transition between looks
      Day→night tip: pin day @ first, night @ last, then Generate
  - Dense filmstrip (more thumbs on short clips; more + horizontal scroll on long)
      Click = preview; Pin frame = keyframe slot; selected / pinned times highlighted
  - Up to 5 keyframes with clear position badges (first / last / 1.61s) + image name
  - Send frame to Studio for cleanup gens → pin still back
  - Prompt + Grok Enhance (transition intent steers dual-anchor language;
      motion / architecture locked; change-only wording)
  - Sticky Generate + est. cost on left rail
  - Generate via Aleph 2.0
  - Result: full in-app play (CONTAIN, no crop) with play/pause controls;
      Show in folder / Send to Resolve / Send to ▾ under player (reachable)
  - Result → Library, Show in folder, Send to Resolve

  applies metadata + optional file move to every selected item.

    Today / This week / This month / All time totals

    Also summarized in Settings → Local spend
- Hide missing media (Settings)

==============================================================================
COST LABELS
==============================================================================
UI cost lines are estimated job totals, not bare rates:
  Est. cost: $X.XX · {unit} ({model})
  e.g. $3.20 · 8s for Veo 3.1 standard ($0.40/s × 8s on fal)
  e.g. $0.90 · 6s for Veo 3.1 Fast ($0.15/s × 6s)
  e.g. $0.03 · 1 image for Flux T2I / Studio Image edit
  e.g. $0.12 · 4 images · 4 sequential runs when API is 1-image-at-a-time
Still batch: always rate × selected # Images (Studio Image, Vision T2I, …).
Estimates are conservative UI ballparks, not billing. No invented audio
surcharge unless the provider quotes one.

==============================================================================
PER-TAB BUSY
==============================================================================
Long-running jobs lock only their scope (image, video, tools, vision,
audio, frame_editor, enhance, …). Other tabs stay usable.

==============================================================================
GROK ENHANCE
==============================================================================
Available across Studio, Tools, Creative Vision, Frame Editor, Audio:
  - Rewrites prompts for the selected model
  - Uses vision when a still/reference is present
  - Scenario-aware constraints
  - Does not auto-switch models
  - Creative Vision: optional “Creative direction for Enhance” field is
    Enhance-only intent (empty = helpers + main prompt only; never raw on Generate)
  - Helper (None) values are omitted from Enhance guidance
  - T2I / I2I Enhance never injects camera motion language
  - Skipped where tools are pure control (e.g. Topaz denoise)
  - Star the enhanced text after Enhance to keep it in Favorites
